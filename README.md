# 🌱 AgroControl

**Gestão inteligente para propriedades rurais.**

O **AgroControl** é uma plataforma de gestão rural desenvolvida para facilitar o controle das atividades de propriedades rurais, centralizando informações de animais, produção, despesas, estoque e usuários em um único sistema.

O objetivo é transformar controles espalhados em cadernos, planilhas e anotações em uma gestão mais organizada, acessível e eficiente.

---

## 🚜 Sobre o projeto

O AgroControl foi desenvolvido pensando principalmente nas necessidades de pequenos e médios produtores rurais que precisam acompanhar a rotina da propriedade sem depender de processos manuais.

A plataforma permite organizar informações importantes da fazenda e acompanhar os principais dados da operação de forma simples.

### Principais funcionalidades

* 🐄 Cadastro e gerenciamento de animais
* 🌾 Cadastro de propriedades rurais
* 📊 Controle de produção
* 💰 Registro de despesas
* 📦 Controle de estoque
* 📅 Organização de atividades e compromissos
* 📈 Relatórios de gestão
* 👥 Gerenciamento de usuários
* 📝 Histórico de produção
* 🔐 Sistema de autenticação e controle de acesso

---

## 💼 Planos

O AgroControl possui diferentes planos de acordo com o tamanho e as necessidades da propriedade.

| Plano           |             Limite | Recursos                                                                                                       |
| --------------- | -----------------: | -------------------------------------------------------------------------------------------------------------- |
| **Básico**      |    Até 100 animais | Controle de produção, registro de despesas e relatórios simples                                                |
| **Produtor**    |    Até 500 animais | Produção, estoque, histórico de produção, até 5 usuários e relatórios completos                                |
| **Fazenda Pro** | Animais ilimitados | Múltiplas propriedades, até 15 usuários, relatórios avançados, suporte prioritário e treinamento personalizado |

> Os recursos e valores dos planos podem ser atualizados conforme a evolução do produto.

## 🚀 Instalação e execução

### 1. Clone o repositório

```bash
git clone git@github.com:JulioVitor/agrocontrol.git
```

Entre no diretório:

```bash
cd agrocontrol
```

### 2. Configure as variáveis de ambiente

Crie o arquivo `.env` de acordo com as configurações necessárias para o ambiente de desenvolvimento.

**Nunca publique credenciais, senhas ou chaves de API no GitHub.**

### 3. Configure o banco de dados

Crie o banco de dados utilizado pelo projeto e execute as migrações ou scripts necessários.

### 4. Execute a aplicação

Utilize os comandos definidos para o backend e frontend da versão atual do projeto.
